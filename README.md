# ⚽ Álbum de Figurinhas da Copa 2026 — FDCO2B

## 📝 Descrição
Este projeto foi desenvolvido como parte da disciplina Fundamentos de Programação 2 (FDCO2B) do curso de Engenharia de Computação da UTFPR — Campus Apucarana. O sistema consiste em um jogo interativo de gerenciamento de Álbum de Figurinhas da Copa do Mundo 2026, desenvolvido em linguagem C, utilizando os conceitos estudados em sala de aula.

O projeto permite cadastrar, gerenciar e visualizar figurinhas da Copa, além de abrir pacotes aleatórios, controlar figurinhas repetidas, realizar trocas e acompanhar o progresso do álbum. Os dados são carregados a partir de arquivos CSV e armazenados dinamicamente em memória, com salvamento em arquivo binário.

---

# 🎮 Mecânica do Jogo — "Álbum da Copa 2026"

O jogador deve completar seu álbum de figurinhas da Copa do Mundo 2026 abrindo pacotes e colecionando jogadores, seleções e figurinhas especiais.

📦 Cada pacote contém 7 figurinhas aleatórias.

✨ O jogador pode:

- Colar novas figurinhas no álbum
- Guardar figurinhas repetidas para troca
- Visualizar o progresso do álbum
- Buscar figurinhas específicas
- Completar seleções nacionais
- Abrir pacotes especiais
- Participar de mini-games para ganhar recompensas

---

# 💡 Funcionalidades Criativas

## 🌟 Sistema de Raridade
As figurinhas possuem níveis de raridade:

- Comum
- Especial

---

## 🎁 Sistema de Abertura de Pacotes
Pacotes são abertos com animações e revelação individual das figurinhas.

---

## 🔄 Sistema de Trocas
O jogador pode utilizar figurinhas repetidas para realizar trocas e completar o álbum.

---

## 🎮 Mini-games
Mini-games disponíveis para ganhar moedas e novos pacotes:

- Pênaltis
- Quiz da Copa
- Desafios rápidos

---

## 📊 Estatísticas do Álbum
O sistema apresenta:

- Percentual completo do álbum
- Quantidade de figurinhas repetidas
- Seleções completas
- Quantidade de figurinhas raras obtidas

# 💻 Linguagem, Conteúdo e Dependências

- Linguagem: C (Padrão C11)
- Interface gráfica: Raylib
- Bibliotecas padrão:
  - stdio.h
  - stdlib.h
  - string.h
  - time.h
  - ctype.h
  - stdbool.h

- Formato de dados:
  - CSV (entrada e exportação)
  - Binário (salvamento)

- Plataforma:
  - Linux ou Windows

- Compilador sugerido:
  - GCC
